# SONORA Festival App

Application React + TypeScript + Tailwind CSS pour une maquette mobile du festival SONORA.

## Installation

```bash
npm install
npm run dev
```

## Structure

```txt
src/
  app/
    App.tsx
    components/sonora/
      BottomNav.tsx
      HomeScreen.tsx
      ProgrammeScreen.tsx
      ArtisteScreen.tsx
      BilletsScreen.tsx
      PanierScreen.tsx
      PaiementScreen.tsx
      ConfirmationScreen.tsx
      InfosScreen.tsx
  styles/
    fonts.css
    index.css
```
